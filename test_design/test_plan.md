## 1. 项目背景

履约中枢是面向订单、库存与履约动作的后台服务，核心业务包括登录鉴权、商品与库存查询、订单创建、订单状态流转、订单取消和库存回补。系统同时输出应用、访问、安全、审计、测试执行和性能日志，用于问题定位、审计追踪和质量度量。

本项目的目标不是只证明“接口能通”，而是通过可复现的测试资产证明以下能力：

- 能基于需求和风险设计功能、边界、异常、安全、并发和性能测试。
- 能把测试用例、自动化脚本、执行结果、缺陷和日志证据关联起来。
- 能对订单状态机、库存一致性、幂等性和权限边界做系统性验证。
- 能定义性能 SLA、执行压测、分析瓶颈并输出可决策的性能结论。
- 能设计企业级结构化日志并验证日志的可关联性、脱敏和审计价值。

## 2. 测试范围

### 2.1 范围内

- 认证：登录、令牌校验、过期令牌、篡改令牌、令牌声明。
- 商品：列表、搜索、分类、分页、详情、创建、库存更新。
- 订单：创建、金额计算、库存扣减、幂等重放、状态流转、取消、库存回补、查询。
- 权限：管理员、履约专员、只读审核员的 RBAC 边界。
- 安全：统一错误结构、参数白名单、SQL 注入防护、安全响应头、日志脱敏、请求 ID 校验。
- 并发：多线程同时下单时库存不超卖。
- 性能：读多写少的混合负载、下单与取消、幂等重放、状态流转、登录成功与失败。
- 可观测性：请求链路、访问日志、安全日志、审计日志、测试执行日志、性能日志。
- 测试流程：测试计划、策略、用例、风险、追踪矩阵、缺陷生命周期、测试报告。

### 2.2 范围外

- 浏览器 UI 自动化。本项目聚焦接口自动化，页面仅作为人工验收入口。
- 第三方支付、真实物流、短信和邮件网关。
- 生产级集群、容器编排、云数据库和外部 WAF。
- 移动端原生客户端。

## 3. 质量目标

| 指标 | 目标值 | 说明 |
| --- | --- | --- |
| 自动化用例通过率 | 100% | 接口、安全、并发、日志用例 |
| 核心模块自动化覆盖率 | 100% | 认证、商品、订单、权限、安全、系统 |
| 语句覆盖率 | 不低于 80% | 以 pytest-cov 结果为准 |
| 性能错误率 | 低于 1% | 业务错误和 HTTP 错误均计入 |
| 读接口 P95 | 低于 300ms | 30 并发、40 秒基线 |
| 写接口 P95 | 低于 800ms | 30 并发、40 秒基线 |
| 吞吐量 | 不低于 50 RPS | 单机 SQLite 演示环境 |
| P0/P1 缺陷遗留 | 0 | 发布前必须关闭或有批准的豁免 |
| 日志 ERROR 数量 | 0 | 性能基线执行窗口内 |

### 4.1 测试数据

- 内置账号：`admin / Admin@123`、`operator / Operator@123`、`viewer / Viewer@123`。
- 内置商品：12 个，覆盖音频设备、电脑外设、桌面设备、存储设备、智能穿戴、办公家具等分类。
- 低库存商品：`SKU-1008`、`SKU-1009`，用于库存预警验证。
- 内置订单：8 笔，覆盖待拣货、拣货中、已发货、已完成、已取消。
- 自动化测试使用临时数据库，每个用例独立初始化，避免用例间污染。
- 性能测试使用 `data/perf.db` 和独立日志目录，执行前重置并预置高库存。

## 8. 进入与退出准则

### 8.1 进入准则

- 被测版本可启动，健康检查通过。
- 数据库结构、种子数据和测试账号可用。
- 接口契约和关键业务规则已确认。
- 自动化环境依赖已安装，测试数据隔离方案可用。
- 性能环境与功能环境隔离，日志目录可写。

### 8.2 退出准则

- 计划内自动化用例全部执行，通过率 100%。
- P0/P1 缺陷全部关闭，P2 缺陷有明确处理结论。
- 语句覆盖率不低于 80%，核心模块关键路径全部覆盖。
- 性能错误率低于 1%，读接口 P95 低于 300ms，写接口 P95 低于 800ms。
- 性能执行窗口内无未解释的 ERROR 日志。
- 质量看板、测试报告、缺陷台账、性能报告和日志证据齐全。

## 9. 缺陷管理

缺陷状态流转为：新建 -> 已确认 -> 修复中 -> 待验证 -> 已关闭。无法复现或业务接受时进入“已拒绝”或“已接受风险”。严重级别定义、响应时限、回归要求和关闭标准见 `defect_management/defect_lifecycle.md`。

## 10. 风险与应对

主要风险包括库存并发竞争、幂等键误用、角色越权、敏感信息进入日志、SQLite 写锁导致性能抖动、测试数据污染、性能结果不可复现等。详细评估见 `test_design/risk_register.csv`。
